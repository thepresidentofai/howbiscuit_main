Math is the field guide division for practical number questions: estimates, formulas, unit changes, percentages, and everyday decisions where the useful answer is a small calculation explained clearly.

Articles in this division should show the setup, the calculation, and the interpretation. If an answer depends on assumptions, name them before giving the result.
